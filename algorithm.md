Algorithm: Smart Medication Assistance

1. Start.
2. Display welcome message.
3. Input child's name, age, weight, and height.
4. Input number of medications (N).
5. Initialize Medication_List as an empty list.
6. Repeat N times:
   a. Input medication name.
   b. Ask if a prescription is available.
   c. If No, display a warning message.
   d. Else, input prescribed dose, frequency, times, and duration.
   e. Add medication information to Medication_List.
7. Display child's information.
8. Display Medication_List.
9. Display completion message.
10. End.
